## Behaviors reviewed and verification notes

- **Duplicate employee prevention:** A unique index on `emp_code` prevents duplicate employee codes.
- **Duplicate daily attendance prevention:** A unique compound index on `emp_code` and `date` prevents duplicate attendance records for the same employee and date.
- **Punch-in concurrency:** A real-MongoDB test sent ten simultaneous requests. Exactly one returned HTTP 201, nine returned HTTP 409, and one attendance record remained.
- **Punch-out concurrency:** A real-MongoDB test sent ten simultaneous requests. Exactly one returned HTTP 200, nine returned HTTP 409, and the attendance record was closed once.
- **Regularization concurrency:** A real-MongoDB test sent two competing corrections. One returned HTTP 200, one returned HTTP 409, and one audit-history entry was stored.
- **API validation:** Automated tests cover invalid inputs and validation responses, including HTTP 422 cases.
- **Calculation boundaries:** Automated tests cover key late-arrival, overtime, work-hour rounding, and related calculation rules.
- **Department summary:** A real-MongoDB integration test verifies headcount, present days, average work hours, and late totals for employees with and without attendance logs.
- **Trend date coverage:** The trend aggregation generates rows for requested dates without attendance records.
- **Automated tests:** The latest full local run passed 21 tests using `python -m pytest -q`.
- **Explain-plan checks:** The five supported endpoints were checked manually on the available local dataset. These checks do not establish performance on a 100,000-record dataset.
- **Items reviewed and retained:** Unique indexes, conditional punch-out updates, and `$push` for regularization history were retained because they provide duplicate prevention, atomic updates, and history preservation.
- **Limitations:** Passing tests do not establish correctness for every possible input or prove production-scale performance. Additional testing is needed for untested edge cases and large datasets.
